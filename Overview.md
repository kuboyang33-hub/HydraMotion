# HydraMotion Overview

HydraMotion is a modular motion platform supporting:
- High‑speed 3D printing
- CNC machining
- Drag‑knife cutting
- Pen plotting

The system uses:
- Swappable toolheads
- Swappable motors (MotorSwitcher)
- Mode‑specific Klipper profiles
- A clean Hardware/Firmware branch separation
